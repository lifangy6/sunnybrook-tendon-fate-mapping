# Poster build environment — scripts/py/
#
# Builds figures/poster/*.png and the .pptx poster files.
#
# Python 3.12, run via uv without a persistent virtualenv:
#
# Run from the repository root:
#
#   uv run --python 3.12 --with-requirements environments/poster.txt \
#       python scripts/py/build_poster_final.py
#
# PROVENANCE — read before trusting these pins.
# Unlike analysis.txt, these versions were NOT read off a live interpreter.
# The poster scripts ran through ephemeral `uv run --with ...` invocations that
# left no environment behind, so the pins below were recovered from the uv
# wheel cache. That cache reflects the most recent resolution rather than a
# guaranteed record of the run that produced the submitted poster, so treat
# them as a close reconstruction, not ground truth. They are internally
# consistent and the poster rebuilds from them.
#
# Note the deliberate version skew against analysis.txt: the poster environment
# resolved newer numpy/pandas/scipy/matplotlib than the analysis environment.
# That is faithful to how the work was actually done. The poster only reads
# finished result files, so the skew does not affect any number reported on it.
